Problem defined: Students were less invested in learning timetables due to the repetitiveness and boring experience, super math bros intends to fix the gap, by targeting a experience in which the student answers, and plays a 10 level racing game.

Computational techniques showcased in this project: 
-  User defined functions.
-  Selections
-  Object-Oriented programming
-  Inheritance
-  Iterations
-  Parameters 
-  Variables 
-  Exception handling
-  Event handling
-  Boolean logic
-  Strong maintenance (ALOT of comments!)
